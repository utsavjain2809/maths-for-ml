# Maths for Machine Learning

A hands-on learning repository focused on understanding the **mathematics behind Machine Learning through Python**.

I’m building these projects step by step as I learn concepts from **linear algebra, calculus, probability, and statistics**, with an emphasis on implementing the underlying mathematics myself.

## What I'm Learning

* **Linear Algebra** — vectors, vector operations, matrices, linear combinations, and more
* **Calculus** — functions, derivatives, gradients, and optimization
* **Probability** — fundamental concepts and distributions
* **Statistics** — descriptive statistics, probability distributions, and inference
* **ML Mathematics** — connecting these concepts to algorithms and models

## Approach

Instead of immediately relying on libraries such as NumPy or SciPy, many early implementations use **plain Python lists and built-in operations**. This helps me focus on understanding what is actually happening mathematically.

As the concepts become more advanced, I’ll gradually introduce appropriate libraries and apply the mathematics to real Machine Learning problems.

**Learning the math. Implementing the concepts. Building toward Machine Learning.**
